# NYC 311 分析说明（Grok）

## 数据与口径

- **来源**：`D:\项目1\原始数据` 下 25 个按 `created_date` 切分的 Parquet，只读扫描。配套清单见 `D:\项目2\input\data_manifest.json`。
- **粒度**：`unique_key` 一条 = 一条 311 **服务请求记录**。全样本 **7,525,498** 条，主键无重复。记录数 ≠ 独立现实事件（同一问题可多次申告）。
- **时间**：创建时间 **2024-09-07** 至 **2026-09-05**。2024-09 从 7 日起、2026-09 只到 5 日，**不是完整月**。分片文件名写到 2026-09-07，库内最晚创建日为 09-05。
- **完整月同比窗**（各 11 个月，排除两个残缺月）  
  - Y1：2024-10-01 ≤ created < 2025-09-01 → **3,293,003**  
  - Y2：2025-10-01 ≤ created < 2026-09-01 → **3,639,698**  
  - 差值 **+346,695（+10.5%）**
- **结案时长**：仅 `status=Closed` 且 `closed_ts ≥ created_ts`。排除关闭早于创建的 1,877 条。用中位数和 P90，不用均值。
- **开放类状态**：Open / In Progress / Assigned / Pending / Started。表示**快照时尚未 Closed**，不是“永久未解决”。

未引入人口、气温或编制等外部数据。没有人均、没有天气回归。

## 主要发现

1. **同比增量来自少数桶，不是全面等比变忙**  
   互斥分解（加总等于 +346,695）：供暖/热水 +63,644（占增量 18.4%）；积雪/结冰 +55,130（15.9%）；违停 +54,955（15.8%）；Street Condition +48,302（13.9%）；堵塞车道 +23,731（6.8%）；其余 +100,933（29.1%）。  
   积雪与 2026-02-24 单日尖峰同向，属于对记录结构的推断，**不是**气象因果证明。Street Condition 大增未单独审计。

2. **冬季改写工单组合**  
   供暖在 1 月可占当月一成以上，夏季接近消失，故“全年第三”会低估冬季权重。2026-02-24 当天 22,805 条中 11,370 条为 Snow or Ice（49.9%），为全样本最高日。2025-01 与 2026-01 **总量几乎相同**（348,180 vs 348,511），但 2026-01 供暖更高、住宅噪声低得多（70,837 → 28,739）。跨年那一周 2025 年多日住宅噪声 3,000–6,000/天，2026 年同期约 750–1,400/天。噪声差异是假说级推断，未验证原因。

3. **结案是双速系统**  
   NYPD（违停、住宅噪声等）中位约 **1.3 小时**；HPD 中位约 **87.5 小时（3.6 天）**，P90 约 37 天。供暖中位 41.8 小时。布朗克斯占完整月样本 **22.1% 工单、35.1% 供暖工单**——供暖负担集中。时长差与职责类型一致，**不能**当作机构绩效排名。

4. **近期指标运动首先是测量问题**  
   2026-08 开放类占比 16.2%，2026-09 残缺月 41.5%，而 2025-01 仅 0.5%。近期 P90 结案变短，是因为慢单还没关掉。2026-08 起 `Water System`/`Sewer` 变为 0，由 `Water Maintenance`/`Sewer Maintenance` 承接；不做合并会误报“供水投诉消失”。

## 关键限制

- 静态快照：越靠近抽取日，关闭率与结案时长越不可比。比较关闭速度不要用 2026-07 以后的创建月。
- 无人口分母，行政区只谈构成，不谈人均。
- Drug Activity、Lead 等降幅大，缺分类/执法材料，不解释。
- 渠道 UNKNOWN 在 2026-03 突然升高，渠道份额序列从该月起不稳定。
