# 项目2｜AI 数据分析 Agent 自主交付评测

基于同一份 NYC311 服务请求数据，观察八个 AI 系统在两轮任务中的交付质量、执行可靠性、耗时与 API 目录价估算。系统自行选题、分析并提交 Excel 和分析说明；失败与人工接管记录单独保留。

## 项目索引

| 项目 | 内容与入口 |
| --- | --- |
| [项目1：NYC311 服务请求分析](https://github.com/Rainbow-bot-bot/nyc311-service-request-analysis) | 数据采集与服务请求分析，包含清洗、SQL、专题核验、Power BI 和项目报告。 |
| [项目2：AI 自主交付评测](https://github.com/Rainbow-bot-bot/nyc311-ai-agent-evaluation) | 当前仓库：比较 AI 完成数据分析任务的实际结果。 |

**项目2测验使用的数据来自项目1采集并保存的 NYC311 原始数据快照。** 原始来源为 [NYC Open Data 311 Service Requests](https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2020-to-Present/erm2-nwe9)。本地快照日期为 2026-09-07，25 份 Parquet 共 7,525,498 条记录、44 个字段；项目2直接只读使用项目1的原始分片，不把项目1的分析结论当作参赛输入。文件清单和哈希见 [input/data_manifest.json](input/data_manifest.json)。

## 本次结果

正式配对为 GPT、Grok、DeepSeek、GLM、Qwen 五个系统。第二轮最终质量分依次为 100、98、95、94、59；Qwen 分项合计为90，按冻结规则封顶59。五系统最终质量均分由88.6变为89.2，增加0.6分。

Gemini 第二轮保留观察评分，不纳入正式配对；Claude 第一轮为 Claude 主导、Grok 收尾的混合交付；Kimi 未形成完整成品。评分裁定、得失分依据和成本口径见完整报告及 [最终评分裁定](./_实验系统/报告素材/最终评分裁定.json)。

每种条件只有一次运行，模型、工具环境和提示条件共同影响结果。本项目描述这次任务的观测表现，不将其解释为跨任务稳定排名或方法提示的独立因果效果。

## 仓库内容与复现范围

`交付成果/` 保存正式报告、工作簿、Notebook和查证页面；各 AI 目录保存已存在的原始提交及分析脚本；`资料/` 保存任务、评分和维护说明；根目录及 `_实验系统/` 的选定文件保存整理、评分叠加和报告生成逻辑。

原始 Parquet、本机原生日志、内部 SQLite、凭据、缓存、备份和历史审查截图不上传。公开材料可用于阅读成品、检查工作簿数据和审阅实现；Notebook从原始运行记录重建、以及重新运行参赛分析，仍需要原环境依赖和相应输入。参赛作品按原样保留，其中的已知错误以评测报告为准。

详细范围见 [公开仓库说明](资料/公开仓库说明.md)。本仓库不宣称仅下载这些文件即可重跑全部实验，也不需要为了阅读报告重新调用付费模型。
