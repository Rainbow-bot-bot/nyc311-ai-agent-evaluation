# 执行入口与历史材料

## 当前维护

| 入口 | 用途 |
| --- | --- |
| `../评测数据处理.py`、`../运行数据处理.cmd` | 从正式Excel同步、核对325条S评分与批注 |
| `../交付成果/01_评测数据整理与验收.ipynb` | 只读核对当前S分项、六维、总分、配对及查证依据 |
| `报告素材/终审.py` | 当前评分同步、缓存总分、下拉定义、文件入口的只读核对 |
| `报告素材/终审交互.py` | 在原生Excel中检查现行选择器，按S分项计算期望值 |
| `报告素材/导出本轮报告.py` | 从正式完整稿和概览Word导出PDF |
| `报告素材/报告字体.py` | 无自动写入的字体辅助函数；现行Word样式以成品为准 |

现行评分标准为[ S v2.2](../资料/评判标准.md)，实际得分及批注在正式Excel中。`最终工作簿验收.json`记录具体检查范围与文件版本。

## 历史源文件

`评测数据处理核心.py`的`extract()`保留SQLite采集和旧Q/R整理逻辑；直接运行已转到当前维护入口。内部SQLite、原生日志及复现记录用于追溯，不用来覆盖现行S评分。

旧`生成分析表.py`，以及报告素材中的`应用最终裁定.py`、`编排详细报告.py`、`编排简洁报告.py`、`补充运行条件.py`、`补充评分细项.py`、`统一数据表格式.py`、`语言格式修正.py`、`导出报告图表.py`、`终审判定.py`保留源代码，执行与导入均已停止在任何文件写入之前。

报告素材中的`各AI分析.json`、`评分依据.json`、`评分细项来源.json`、`比较表定义.json`、`研究表定义.json`、`图表来源.json`、`简洁版图表来源.json`对应旧生成流程。它们与旧图片、历史Q/R Notebook及旧裁定一起保留供回查；当前报告以正式Word和PDF为准。

本机额外保存的采集、复现、重评和排版试作目录属于过程记录，保持原处，不能直接重建正式交付。各AI目录的脚本属于原始参赛作品，按原样保留；其中的问题由报告评价，不替参赛者修改。
