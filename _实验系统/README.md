# 执行入口

## 当前维护

| 入口 | 用途 |
| --- | --- |
| `../评测数据处理.py`、`../运行数据处理.cmd` | 从正式Excel同步、核对325条S评分与批注 |
| `../交付成果/01_评测数据整理与验收.ipynb` | 只读核对当前S分项、六维、总分、配对及查证依据 |
| `报告素材/终审.py` | 当前评分同步、缓存总分、下拉定义、文件入口的只读核对 |
| `报告素材/终审交互.py` | 在原生Excel中检查现行选择器，按S分项计算期望值 |
| `报告素材/导出本轮报告.py` | 从正式完整稿和概览Word导出PDF |
| `报告素材/报告字体.py` | 无自动写入的字体辅助函数；现行Word样式以成品为准 |

评分标准见[评判标准](../资料/评判标准.md)，实际得分及批注在正式Excel中。`最终工作簿验收.json`记录具体检查范围与文件版本。

## 采集与参赛作品

`评测数据处理核心.py`的`extract()`从内部SQLite整理运行、动作和核验记录。直接运行该文件会转到当前维护入口。内部SQLite和原生日志不在本仓库，不能覆盖现行 S 评分。

当前报告以`交付成果`中的正式 Word、PDF 和 Markdown 为准。报告配图在`报告素材`，由 Markdown 报告直接引用。各AI目录的脚本属于原始参赛作品，按原样保留；其中的问题由报告评价，不替参赛者修改。
