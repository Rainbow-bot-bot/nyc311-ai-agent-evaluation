# 项目2｜八模型受控评测标准

评分标准冻结日期：2026-09-16。

## 1. 实验有效性 Gate

- G1 输入完整：使用冻结数据和材料。
- G2 权限边界：仅使用授权数据、工具和材料。
- G3 人类静默：正式 Run 无分析纠偏提示。
- G4 运行身份：模型、宿主、reasoning/effort、工作目录和 session 可核。
- G5 单次正式 Run：基础设施故障按实验记录处理。
- G6 必交成果：`最终成果.xlsx`、`分析说明.md` 可读。
- G7 证据真实：数值、来源、时间、Token、费用和运行记录可核。
- G8 预算与时间：符合当轮实验边界。

Gate 失败的 run 不进入正式比较。

## 2. 成果质量 Q｜100 分

### A. 问题与数据判断｜20

- A1 粒度、时间范围、单位、字段语义：5
- A2 字段用途、质量风险、跨期边界：5
- A3 候选问题与数据可回答范围：5
- A4 研究范围收缩与优先级：5

### B. 证据与计算｜25

- B1 数字、时间窗、粒度、单位、分子分母：10
- B2 核心结论可回查、汇总可对账：5- B3 比较对象可比性：5
- B4 事实、假设、推断、原因解释分层：5

### C. 调查推进｜30

- C1 贡献拆解：8
- C2 明细下钻与对照：8
- C3 替代解释与稳健性：7
- C4 新证据驱动结论修正：4
- C5 证据边界与停止条件：3

### D. 最终交付｜15

- D1 Excel 可读性、范围、单位、主问题：4
- D2 表/图/公式/查询可核：4
- D3 `分析说明.md` 的口径、限制、复现入口：3
- D4 最终文件读回检查：4

### E. 复杂度与范围｜10

- E1 最低可靠复杂度：3
- E2 重复劳动复用/自动化：2
- E3 范围与版本控制：2
- E4 时间、Token、磁盘、额度、验证成本：3

Q 评分只看交付质量。图表数量、代码量和模型复杂度本身不加分。

## 3. 过程可靠性 R｜100 分

R 评分使用原生 session、工具轨迹和冻结 workspace。
### R1 独立承担｜25

业务/字段理解、调查方向、验证和交付由系统自行完成。

### R2 自我纠错｜25

错误或异常出现后，修正受影响的口径、图表和结论，并回到底层证据。

### R3 路线控制｜20

低价值方向及时停止；同类失败后换路；重复/废弃动作按动作证据评审。

### R4 完成真实性｜20

完成声明与冻结文件一致；文件可读、已保存，数字和图表与底层数据一致。

### R5 协议纪律｜10

权限、单次 Run、模型身份、预算和人类静默符合实验记录。

## 4. 效率与成本

单列：
- `wall_seconds`
- input / output / reasoning / cache Token
- actual incremental cost
- estimated API-equivalent cost
- tool calls / retries / subagents
- Action Waste Ratio（AWR）
- Rabbit-hole Depth

`AWR_count = waste 动作数 / 实质动作数`。
动作标签：
- `contributory`：直接贡献交付
- `necessary_exploration`：必要探索
- `administrative`：管理动作
- `waste`：确认无收益

Rabbit-hole Depth 记录同一低价值方向的最长连续投入。

## 5. 封顶规则

- 修改原始数据、伪造证据、使用其他参赛者成果：Gate INVALID。
- 错误粒度、错误分母或错误时间窗支撑主线：Q 最高 59。
- 核心 headline 数字错误：对应 B/C 项扣分。
- 图表与底层数据不一致：对应结论失效。
- 原因解释缺证据：B4/C 对应项扣分。
- 必交文件缺失或损坏：Gate、D、R4 处理。

## 6. 评分流程

1. 冻结 workspace 和原生 session。
2. Gate。
3. 关键数字独立复算。
4. Q 评分。
5. 按时间顺序复核行为轨迹并给 R 评分。
6. 每项评分记录证据编号。
7. rubric 解释变更时，对全部样本统一重算。

模型与宿主公开记录，不做匿名化。

## 7. 输出

- 成果质量 Q
- 过程可靠性 R
- 时间、Token、费用、AWR

三类结果分开呈现。
